# Replication update — 9 September 2026

Dataset: PELIC v1.1, upstream commit c4526baeb8fb5d69732f9e2a8e1430b41ed38c53.
Dependencies: requirements.txt (Python 3.9 analysis environment).
Run instructions: README.md. File hashes: results/revision_checksums.json.

The release includes primary estimates, chronology audit, task/length/duplication
sensitivities, learner-question variance components, leave-one-text-out frequency
sensitivity, paired transitions, exploratory L1 estimates, and direct coefficient
contrasts. Both revised figures are generated by src/plot_associations.py.

Validation for this update: five primary models were refitted by the standalone
contrast script, all converged, and coefficients agreed with the recorded primary
fits to 1e-7. The resulting contrast estimates, intervals, p values and BH-adjusted
p values matched the manuscript analysis to numerical precision. Optimization
emitted singular-covariance warnings; final convergence was checked explicitly.
The full corpus metric extraction and all sensitivity fits were not rerun in this
publication-only update; their code and previously recorded aggregate results are
included. Python compilation and patch-whitespace checks passed.

Interpretation: the question variance component is nested within learner; the
historical output label does not imply crossed prompt control. Course-level and
prompt-set effects cannot be separated because question IDs do not span levels.
The direct contrasts are post hoc, with multiplicity adjustment across five tests.

The row-level metrics needed by the contrast script are generated locally by
src/run_experiment.py after obtaining PELIC from its official source. They are not
redistributed. No learner text, row-level identifier, manuscript, editorial note,
credential, or local-machine path is included in this release.
